# AI/ML Portfolio Website

A modern production-level portfolio website showcasing projects, skills, and experience in Artificial Intelligence, Machine Learning, Data Analytics, and Software Development.

---

## Features

- Modern Responsive UI
- Animated Hero Section
- Glassmorphism Design
- Smooth Hover Effects
- Project Showcase
- Skills & Experience Sections
- Contact Information
- Scroll Animations
- Mobile Responsive Design

---

## Technologies Used

- React
- Vite
- Tailwind CSS
- Framer Motion
- JavaScript

---

## Projects Included

### Amazon Sales Dashboard
Interactive Power BI dashboard analyzing Amazon sales trends and business insights.

### Educational Recommendation System
AI-powered recommendation system using Machine Learning techniques.

### Water Quality Prediction
Machine learning model for predicting water quality using regression algorithms.
